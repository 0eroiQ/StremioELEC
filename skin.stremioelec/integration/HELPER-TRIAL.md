# Bingie + Stremio playback trial

## 0.5.0 setup and subtitles (2026-09-23)

Fresh skin profiles now enter the QR window directly. After account import,
`setup_profile.prepare` writes Continue Watching plus nine distinct TMDb Helper
catalog rows, with 20 items per row, installs the bundled Helper player definition,
and sets movie/episode playback defaults. Completion is recorded separately from
the account: reconnecting does not overwrite customized Home/settings. Existing
users can explicitly apply the layout from the addon's settings; files are backed
up before replacement. Existing Kodi language choices are never changed.

Hardware policy is deliberately conservative, NOT full capability detection:
retain Kodi decoder/output/resolution defaults, disable unverified passthrough
where that setting is exposed, disable automatic refresh switching and
sync-to-display once. The setup record stores platform, previous settings and
successful writes. N60 EDID/ELD, codec support and passthrough verification remain
required before a hardware-optimized profile can be claimed.

Stremio subtitle resources and stream-provided subtitles are filtered by Kodi's
download-language set, with preferred subtitle language ranked first. Additional
languages have deterministic alphabetical order, not invented user priority.
Automatic preparation downloads at most one successful candidate when Kodi's
auto-download setting is enabled, trying at most two candidates. When disabled,
video startup does not query subtitle providers. Manual results are available via
the standard Kodi subtitle download service and the addon's current-video action.
Only selected text SRT/VTT/ASS files are downloaded; archives/binary/HTML are rejected.
No video hash is computed yet, so subtitle timing/release matches are not guaranteed.
Embedded track selection remains Kodi's responsibility and is not hidden/filtered
by this addon. A subtitle provider may itself perform generation or charge quota
when its download URL is used; account configuration remains authoritative.

Observed: ten Home rows generated and the last row navigated in portable Kodi;
existing four subtitle languages preserved; standard Kodi subtitle dialog showed
a Croatian result from the user's provider. The result was AI-labelled, so its
download/generation was not triggered during validation. Automatic download is
covered by mocks but not yet a successful end-to-end live subtitle display test.
Full fresh device-link sign-in, N60 hardware, progress writeback, resume and timing
benchmarks are still separate acceptance gates.

This is an opt-in macOS portable Kodi trial, not an onboarding migration or a LibreELEC release.

- `trial-home.xml`: four Skin Shortcuts rows: Stremio Continue Watching, Helper Popular Movies, Top Rated Movies, Popular TV Shows.
- `helper-players/stremioelec.json`: install in the profile's `addon_data/plugin.video.tmdb.bingie.helper/players/` directory.
- Helper movie default: `stremioelec.json play_movie`; episode default: `stremioelec.json play_episode`.
- Deploy `default.py` and `helper_player.py` together to the existing StremioELEC addon.
- Back up existing shortcut configuration, Helper settings/players, addon source and skin settings before applying. Stop Kodi before replacing profile files.

The player adapter accepts an IMDb movie ID or a series IMDb ID plus exact season/episode. Invalid/missing IDs fail closed; it does not guess by title. Helper's `{imdb}` field is the show IMDb ID for episodes. Sources are requested only from account-imported providers and selected in a dialog. Cancellation resolves the Kodi request unsuccessfully. Provider URLs are not persisted in player configuration.

Current limitations: only supported direct HTTP(S) sources, no torrent engine, custom proxy headers or DRM. No Stremio progress writeback or resume seeking has been added. Continue Watching artwork may be incomplete in imported account records. The three online rows use Helper's own cache and artwork behavior; no performance optimization or benchmark is claimed.

Runtime backups for this trial are outside the repository in `work/kodi-runtime/backups/trial-20260923-home-player` beneath the Codex task workspace. They may contain private settings and must not be published. Restore those exact saved profile folders and addon files with Kodi closed; remove the trial player/settings only if they did not exist in the backup. Do not replace the whole profile or remove account data.

Automated checks: `python3 -m unittest discover -s integration -p 'test_*.py'`.
